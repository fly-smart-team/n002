# 덕이중학교 정류장 시간표

경기 고양 덕이중학교 정류장(20675)의 버스 시간표 웹페이지입니다. 휴대폰 홈 화면에 추가해 앱처럼 쓸 수 있습니다.

## 노선

| 방면 | 노선 | 행선지 | 시간표 출처 |
|---|---|---|---|
| 대화역 방면 | N002 (마을) | 대화역 | 실측 통계 |
| 대화역 방면 | 10 (일반) | 대화역 | 실측 통계 |
| 탄현역 방면 | 074 (마을) | 탄현역 · 후곡 | 공식 시간표 |
| 탄현역 방면 | 071 (마을) | 탄현역 · 일산시장 | 실측 통계 |

- 평일과 토·일·공휴일 시간표를 나눠 보여줍니다. 토요일과 일요일은 같은 시간표입니다.
- 공휴일은 주말 시간표를 따른다고 가정했습니다(아직 실측 확인 전).
- 실측 통계는 2026-11-01 ~ 11-09 경기도 버스도착정보 API를 2분 간격으로 수집해 정류장 통과 시각을 추정한 것입니다. 오차는 약 1~2분입니다.

## 파일

- `index.html` — 시간표 페이지 (외부 의존성 없이 단독 실행, 글꼴만 Google Fonts 사용)
- `collector/bus_collector.gs` — 도착정보 수집용 Google Apps Script. `SERVICE_KEY`에 data.go.kr 인증키를 넣어 사용합니다. 인증키는 저장소에 올리지 마세요.
